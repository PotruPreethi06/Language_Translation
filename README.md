🌐 Language Translation Tool

A Python-based Language Translation Tool developed using Tkinter and Google Translate API to provide real-time text translation between multiple languages. The application allows users to enter text, select source and target languages, and instantly view translated results. Additional features such as copy-to-clipboard and text-to-speech improve accessibility and user experience. This project demonstrates API integration, GUI development, and multilingual processing using Python.

✨ Features:
Translate text between multiple languages in real time
User-friendly GUI built with Tkinter
Source and target language selection
Copy translated text with one click
Text-to-speech functionality for translated output

🛠️ Technologies Used:
Python
Tkinter
Googletrans API
gTTS (Google Text-to-Speech)
Playsound


🎯 Project Objective:
To develop a multilingual translation application that enables seamless communication by converting text from one language to another while providing additional accessibility features.


🔄 Workflow
User enters text into the application.
User selects source and target languages.
The application sends text to the translation API.
The API returns translated text.
Translated output is displayed.
User can copy the text or convert it to speech.
Process completes successfully.


🚀 How to Run:
Install required libraries:
pip install googletrans==4.0.0-rc1 gtts playsound
Run the application:
python app.py
Enter text, choose languages, translate, copy, or listen to the translated output.


📌 Outcome:
Successfully developed a desktop-based translation system with translation, copy, and speech features, enhancing multilingual communication and accessibility.
